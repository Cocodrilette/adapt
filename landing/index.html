Everything included

One server, the whole stack

Adapt isn't just an API generator. It's a complete platform with auth, search, admin tools, and an MCP server for AI agents.

{ }

REST API auto-generated

Every dataset gets full CRUD endpoints with filtering, sorting, pagination, and schema validation — no code required.

▦

Interactive DataTables

Tabular data gets a browser UI with inline editing, column sorting, and search. Share a URL, not a CSV file.

🔐

Auth & RBAC built in

Session-based auth, API keys, users, groups, and per-resource permissions. Secure by default, configurable when you need it.

⌕

Full-text search

Search across every resource — datasets, documents, media metadata — with permission-filtered results via SQLite FTS5.

◈

MCP server for AI agents

Give Claude Code, Cursor, and other AI tools structured access to your data through the built-in MCP server at /mcp.

▶

Media streaming

Audio and video files get streaming endpoints, metadata extraction, thumbnail generation, and a browser gallery.

One command. Everything else is automatic.
